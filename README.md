# MedDex

This repository only hosts the published, password-protected build of MedDex, a medical dataset catalog.

The page at https://iu-ultraman.github.io/MedDex/ is encrypted with [StatiCrypt](https://github.com/robinmoisson/staticrypt); its content cannot be read without the password. The source cards live in a private repository and this repository is overwritten on every publish, so please don't open issues or pull requests here.
